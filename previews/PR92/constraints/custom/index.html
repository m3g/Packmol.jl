Custom constraints

CustomConstraint(f; gradient = nothing, weight = 5.0)

A region defined by a function of the position: the atoms are kept where f(x) ≤ 0, for x the position of an atom (an SVector{3}, in Å). Any region that can be written as an inequality can be used, combined with the other constraints of the molecule as usual. This constraint is available only in Julia code, not in input files or in the packmol executable.

Outside the region, the penalty is weight * f(x)^2, so f should grow with the distance to the region. A signed distance is the best choice (as f(x) = norm(x) - R, for a sphere of radius R), but any function that is positive outside the region, and grows smoothly away from it, works. The packing also needs the gradient of f:

  • if gradient is not given, it is computed by central finite differences (six evaluations of f for each atom outside the region);
  • it can be computed exactly by automatic differentiation, for example with ForwardDiff.jl: gradient = x -> ForwardDiff.gradient(f, x);
  • or it can be written by hand, for a function with a simple gradient.
Packmol.CustomConstraint — Type
CustomConstraint(f; gradient = nothing, weight = 5.0, T = Float64)

A constraint defined by a function of the position: the atoms are kept in the region where f(x) ≤ 0, for x the position of an atom (an SVector{3}, in Å). Outside the region, the penalty is weight * f(x)^2, so f should grow with the distance to the region (as f(x) = norm(x) - R, for a sphere of radius R).

gradient(x) is the gradient of f at x. If it is not given, it is computed by central finite differences (6 evaluations of f). It can be computed exactly by automatic differentiation, for example with gradient = x -> ForwardDiff.gradient(f, x).

It is a constraint of whole molecules (constraints) or of some of their atoms (atom_constraints), as the other constraints. There is no input file syntax for it.

Example

using Packmol, LinearAlgebra# Inside a torus of radii 20 and 6 Å around the z axistorus = CustomConstraint(x -> hypot(hypot(x[1], x[2]) - 20, x[3]) - 6)water = structure_type("water.pdb"; number = 500, constraints = [torus])
source

Example

Water in a torus around the z axis, with radii of 14 and 6 Å (the distance between the center of the tube and the axis, and the radius of the tube). The distance of a point to the circle of the center of the tube, minus the radius of the tube, is the signed distance to the surface of the torus. The torus has a volume of about 9950 Å³, which holds 330 water molecules at 1 g/mL:

using Packmol, PDBTools, ForwardDifftorus(x) = hypot(hypot(x[1], x[2]) - 14, x[3]) - 6water = structure_type("water.pdb";    number = 330,    constraints = [CustomConstraint(torus; gradient = x -> ForwardDiff.gradient(torus, x))],)system = PackmolSystem([water]; tolerance = 2.0, output = "torus.pdb")packmol(system)visualize(get_atoms(system))

Custom constraints can also be applied to some atoms of each molecule, with atom_constraints, as the other constraints (see Constraints on some atoms).
