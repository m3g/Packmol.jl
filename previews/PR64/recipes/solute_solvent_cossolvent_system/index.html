Solute-Solvent-Cossolvent system

Here, SolutionBoxUSC stands for Solute (U), Solvent (S), and Cossolvent (C). Concentrations can be given in molarity ("mol/L"), molar fraction ("x"), mass fraction ("w/w" or "mm"), or volume fraction ("v/v" or "vv"); see Concentration Unit Conversion for the full list of unit aliases.

Packmol.SolutionBoxUSC — Type
SolutionBoxUSC(; 
    solute_pdbfile::String, 
    solvent_pdbfile::String,
    cossolvent_pdbfile::String,
    density_table::Matrix{<:Number},
    concentration_unit = "x",
    solute_molar_mass = nothing, # optional
    solvent_molar_mass = nothing, # optional
    cossolvent_molar_mass = nothing, # optional
)

Setup a system composed of a solute (U) a solvent (S) and a cossolvent (C).

The concentration units of the density table can be provided explicitly and are assumed by default to be the molar fraction, x, of the cossolvent. The density units are assumed to be g/mL unless the values are explicitly provided with Unitful units.

The molar masses of the solute, solvent, and cossolvent can be provided manually. If not, they will be computed from the atom types in the PDB file.

Packmol.write_packmol_input — Method
write_packmol_input(
    system::SolutionBoxUSC;
    concentration::Number,
    input="box.inp",
    output="system.pdb",
    # box size
    box_sides::AbstractVector{<:Number}, # or
    margin::Number,
    pbc::Symbol = :cubic,
)

Function that generates an input file for Packmol.

The box sides are given in Ångströms, and can be provided as a vector of 3 elements. Alternatively, the margin can be provided, and the box sides will be calculated as the maximum and minimum coordinates of the solute plus the margin in all 3 dimensions.

pbc selects the shape of the periodic cell: :cubic (the default) forces all 3 sides to their maximum, :orthorhombic keeps box_sides/margin as given (possibly with unequal sides), and :dodecahedral/:octahedral build a rhombic dodecahedron/truncated octahedron cell (see dodecahedral_unitcell/ octahedral_unitcell) of size equal to that same maximum side.

Packmol.packmol — Method
packmol(
    system::SolutionBoxUSC;
    concentration::Number,
    concentration_units::Union{Nothing,String} = nothing,
    output="system.pdb",
    # box size
    box_sides::AbstractVector{<:Number}, # or
    margin::Number,
    pbc::Symbol = :cubic,
    kwargs...,
)

Builds and packs a Solute + Solvent + Cossolvent system, without writing an input file.

It is equivalent to calling write_packmol_input followed by packmol on the resulting file.

concentration, concentration_units, output, box_sides, margin, and pbc behave as in write_packmol_input. Any other keyword (nloop, iprint, seed, optimizer, ...) is forwarded to the packing engine — see packmol(::PackmolSystem).

Returns the built PackmolSystem, with the packing outcome in its .status field — see packmol(::PackmolSystem).

Packmol.convert_concentration — Function
convert_concentration(system::SolutionBoxUSC, concentration, units::Pair{String,String})

Converts the concentration of the cossolvent between units.

The conversion is first(units) => last(units), using the density of the solution at that concentration (interpolated from the density table of the system) and the molar masses of the solvent and the cossolvent. The units are "mol/L" (molarity), "x" (molar fraction), "w/w" or "mm" (mass fraction), "v/v" or "vv" (volume fraction), or any of their aliases (see Concentration Unit Conversion). Molarities are returned with units.

Example

convert_concentration(system, 0.2, "x" => "mol/L")

Packmol.convert_density_table! — Function
convert_density_table!(system::SolutionBoxUSC, target_units::String)

Sets the units of the concentrations of the system to target_units: the units in which its density table is shown, and the default units of the concentration given to write_packmol_input and packmol. The units are those of convert_concentration. Returns the system.

Example

convert_density_table!(system, "mol/L")

Packmol.get_density_table — Function
get_density_table(system::SolutionBoxUSC)

Returns the density table of the system, as a matrix.

The first column has the concentrations of the cossolvent, in the units of the system (see convert_density_table!), and the second one the densities of the solution, in g/mL.

or, equivalently, pack it directly with packmol(system; concentration=0.5, margin=20.0, output="system.pdb").

concentration_units can be passed to interpret concentration in units other than the density table's own (e.g. request a concentration in "mol/L" even though the table above is indexed by molar fraction). margin, box_sides, and pbc behave as in SolutionBoxUS.

Converting concentrations

convert_concentration converts a concentration of the cossolvent between units, using the density of the solution at that concentration (interpolated from the density table) and the molar masses of the components. For example, the molarity of ethanol at a molar fraction of 0.5:

convert_concentration(system, 0.5, "x" => "mol/L")
13.48866825794416 mol L^-1

convert_density_table! changes the units in which the system takes and shows the concentrations: after it, concentration in write_packmol_input is read in the new units, and get_density_table returns the table in them:

Volume fractions

The volume fraction is the IUPAC one: the volume of the pure cossolvent divided by the sum of the volumes of the pure components, before mixing. Computing it requires the densities of the pure solvent and cossolvent, so the density table must include both (concentrations 0 and 1 in molar fraction).
