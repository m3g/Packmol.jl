Tutorials

The tutorials build complete systems, from a box with a mixture of two molecules to a virion with 2.8 million particles. The first ones are the classic examples of Packmol (the bilayer and the vesicle redone with an all-atom lipid, at realistic densities, the vesicle as nanoliposomes); the others use more of the features of Packmol.jl: fixed molecules, periodic cells of different shapes, curved surfaces, crystals.

TutorialSystem
Water and ureaA mixture of two molecules in a box
Water–chloroform interfaceTwo solvents in adjacent boxes and a fixed molecule at the interface
Lipid bilayerA POPC bilayer in water, with periodic boundary conditions: lipids oriented by constraints on two of their atoms
NanoliposomesTwo POPC nanoliposomes in water, in a truncated octahedron periodic cell: lipid layers in spherical shells, and how curvature limits how many lipids fit in each leaflet
Solvated proteinA fixed protein in water and ions, in a rhombic dodecahedron periodic cell
Protein in glycerol and waterA fixed protein in a mixture, in a periodic box
Water drop on graphiteA fixed surface, and a drop shaped by constraints
Polymer in DMFA fixed polymer in a solvent, in a periodic box
Carbon nanotube filled with waterA fixed nanotube crossing the periodic boundary, with water inside and outside
Gases in a zeoliteA fixed crystal in its triclinic periodic cell, with gases in its pores
Liquid crystalsOriented molecules (rotation constraints): a nematic phase and a twisted nematic cell
Zika virionA large system: 2.2 million particles in membranes and spherical shells

How the tutorials are organized

Each tutorial starts with an image of the final system and the files it needs, and, when the numbers of molecules are not trivial, how they follow from the densities and the volumes of the regions. Then the same system is built in two ways:

  • Command line: an input file, run with the packmol executable, as with Fortran Packmol (see Installation).
  • Julia: the same system defined with Julia code, with structure_type, PackmolSystem and packmol (see Defining systems in Julia).

The two are equivalent, and either can be followed alone. The input files of the Input files section and the functions of the Julia API section are linked where they are first used.

Getting the files

Each tutorial links to the files it needs: the input file and the structures of the molecules (the Zika virion, which is larger, is a separate download). Put them in a directory, and run the examples from it: the paths in an input file are relative to the directory of the input file, and those in a Julia script to the current directory.

Checking the initial placement

First check the initial placement of the molecules

Every input file of the tutorials has the line

# check_initial_placement

Uncomment it (remove the #), and run the input file: Packmol then only places each molecule in its region, satisfying the constraints, writes this initial placement to the output file, and stops, without packing. This takes a fraction of the time of the packing (30 seconds, for the virion that takes 7 minutes). The molecules may still overlap, but a look at the output file in a molecular visualization program shows whether the constraints put them where intended. When they do, comment the line again, and run the packing.

In Julia, the same is check_initial_placement = true in PackmolSystem (commented in the code of the tutorials).

If the constraints cannot be satisfied at all, even without the distances between the molecules, Packmol stops after the initial placement with an error (unless the continue_failed_initial_packing keyword is set): that is almost always a sign of wrong constraints, cheaper to find before the packing than after it.

The tutorials of non-trivial systems show the initial placement before the packed system.
