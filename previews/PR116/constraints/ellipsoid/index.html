Ellipsoid

inside ellipsoid  cx cy cz  a b c  scale
outside ellipsoid cx cy cz  a b c  scale

An axis-aligned ellipsoid centered at (cx,cy,cz) with semi-axes a, b, c along x, y, z respectively, uniformly scaled by the dimensionless scale factor — i.e. the effective semi-axes are a*scale, b*scale, c*scale. scale lets the same base ellipsoid (e.g. one fit to a reference structure) be grown or shrunk without recomputing a, b, c.

The penalty of an atom outside the region is weight * (m (ρ - scale))^2, for ρ^2 = ((x-cx)/a)^2 + ((y-cy)/b)^2 + ((z-cz)/c)^2 and m = min(a, b, c): the violation is about the distance (in Å) to the surface of the ellipsoid, the exact distance for a sphere. (Fortran Packmol uses ρ^2 - scale^2, which has no units: for large ellipsoids, of hundreds of Å, its gradient at small violations was below the stopping tolerance of the optimizer, and the placement of the molecules did not converge.) The region is the same.

Example

81 water molecules (about 1 g/mL) in an ellipsoid with semi-axes of 12, 8 and 6 Å:

structure water.pdb
    number 81
    inside ellipsoid 0. 0. 0. 12. 8. 6. 1.0
end structure

The same system, packed with the Julia API and shown with the visualize function of PDBTools.jl:

using Packmol, PDBToolswater = structure_type("water.pdb";    number = 81,    constraints = [InsideEllipsoid([0., 0., 0.], 12., 8., 6., 1.0)],)system = PackmolSystem([water]; tolerance = 2.0, output = "ellipsoid.pdb")packmol(system)visualize(get_atoms(system))
