Tutorials

The first tutorials are the classic examples of Packmol, followed by systems that use more of its features. Each one shows the same system built in two ways:

  • Command line: an input file, run with the packmol executable, as with Fortran Packmol (see Home for how to install it).
  • Julia: the same system defined with Julia code, with structure_type, PackmolSystem and packmol (see Defining systems in Julia).
TutorialSystem
Water and ureaA mixture of two molecules in a box
Water–chloroform interfaceTwo solvents in adjacent boxes and a fixed molecule at the interface
Lipid bilayerOriented molecules, with constraints on some of their atoms
Spherical vesicleLipid layers and water in spherical shells
Solvated proteinA fixed protein in a sphere of water and ions
Protein in glycerol and waterA fixed protein in a mixture, in a periodic box
Water drop on graphiteA fixed surface, and a drop shaped by constraints
Polymer in DMFA polymer in a solvent, in a periodic box
Carbon nanotube filled with waterA fixed nanotube crossing the periodic boundary, with water inside and outside
Gases in a zeoliteA fixed crystal in its triclinic periodic cell, with gases in its pores
Zika virionA large system: 2.8 million particles in membranes and spherical shells

Getting the files

The input and structure files of the classic examples can be downloaded at once from the Packmol site (examples.tar.gz or examples.zip). Each tutorial links to the files it needs. Run the examples from the directory that contains the files: the paths in an input file are relative to the directory of the input file, and those in a Julia script to the current directory.

The input files of the Packmol site also come in commented versions (*-comment.inp), which are the ones shown in the tutorials.
